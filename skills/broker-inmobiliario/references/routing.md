# Enrutamiento

Selecciona el grupo minimo que cubra el riesgo real.

| Necesidad | Agente principal | Apoyo frecuente |
|---|---|---|
| Captar propietario o inmueble | captacion | valoracion_mercado, crm_demanda |
| Estimar estrategia de precio | valoracion_mercado | legal_cumplimiento |
| Ordenar leads o cruzar demanda | crm_demanda | visitas_seguimiento |
| Revisar expediente del inmueble | documentacion_inmueble | legal_cumplimiento |
| Contrato, arras, alquiler o derechos | legal_cumplimiento | administracion_cierre |
| Crear o adaptar anuncio | publicacion_portales | marketing_inmobiliario, legal_cumplimiento |
| Campana o contenido | marketing_inmobiliario | publicacion_portales |
| Visitas, feedback o seguimiento | visitas_seguimiento | crm_demanda |
| Oferta, objecion o negociacion | negociacion_ofertas | legal_cumplimiento |
| Hipoteca o capacidad financiera | financiacion | legal_cumplimiento |
| Notaria, certificados, cobros o llaves | administracion_cierre | legal_cumplimiento |
| Impuestos o posventa | fiscal_posventa | administracion_cierre |
| Indicadores y aprendizaje | reporting_conocimiento | coordinador |

COORDINADOR interviene cuando hay mas de una tarea, dependencia, plazo o aprendizaje. CALIDAD interviene siempre antes del cierre.
