# Base de conocimiento

Esta carpeta contiene conocimiento durable y revisado. No contiene expedientes operativos completos ni originales confidenciales.

- `global/`: fuentes y procedimientos comunes para Espana.
- `agencies/`: contexto estable y autorizado por agencia.
- `proposals/`: candidatos pendientes de revision.
- `templates/`: esquemas Markdown obligatorios.

Antes de usar una entrada, comprueba `status`, jurisdiccion, fecha efectiva y proxima revision. Si falta evidencia o esta vencida, tratala como contexto no confirmado y vuelve a verificar.
